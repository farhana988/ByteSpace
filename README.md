# ByteSpace

A modern and responsive E-Learning Platform built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

ByteSpace is currently in its initial development stage, focusing on creating a clean learning experience with a modern landing page and user authentication interfaces.

- Live Website URL: https://byte-space-lilac.vercel.app

## ✨ Features

- Responsive and modern landing page

- Clean navigation and content sections

- User login page
- User registration page

- Responsive design for different screen sizes

- Reusable UI components

- Consistent and modern design system

## 🛠️ Tech Stack

- Next.js

- TypeScript

- Tailwind CSS

- shadcn/ui

## 🧪 Development & Running Locally

### Clone the Repository

```bash
https://github.com/farhana988/ByteSpace.git
cd ByteSpace
```

### Install Dependencies

```bash
npm install
```

### Run the Frontend

```bash
npm run dev
```
